# Public Release Scope

This repository was generated by `scripts/sync_public_release.py` for the
v1.2.0 public code release.

It contains the code-oriented public release whitelist:

- Python packages and CLI
- JSON schemas and demo configs
- tests
- WebUI source and package metadata
- selected public docs and specs
- license and third-party notice files

It intentionally excludes manuscript drafts, literature extraction materials,
sample data, generated outputs, reference repositories, caches, and local
platform metadata.

The public manifest is recorded in `PUBLIC_RELEASE_MANIFEST.json`. Runtime
outputs generated by users are expected to live outside version control, usually
under a local `outputs/` directory.
