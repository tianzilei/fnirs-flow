# Public Documentation Index

Last updated: 2026-07-15

This directory contains the documentation that is intentionally included in the
public code release. Private planning notes, manuscript drafts, literature
extraction workspaces, audit logs, generated outputs, and local sample data are
not part of this repository.

## Release Validation

Run these checks from the repository root:

```bash
python -m pytest tests -q
python -m ruff check fnirs_flow cli.py scripts tests

cd webui
npm ci
npm run build
```

## Not Included

The public sync excludes:

- private manuscript and submission drafts
- literature extraction source material
- local sample datasets
- generated analysis outputs
- reference repository mirrors
- local agent/cache/platform metadata
- legacy non-release code

See `PUBLIC_RELEASE_MANIFEST.json` for the exact file manifest generated by the
release sync script.
